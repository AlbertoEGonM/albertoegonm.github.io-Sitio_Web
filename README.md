# Portafolio de Alberto González

Sitio estático bilingüe, listo para GitHub Pages.

## Publicar
1. Descomprime este ZIP.
2. Sube todo su contenido a la raíz del repositorio. index.html debe quedar directamente en la raíz, junto a styles.css, app.js, certificates.js y la carpeta assets/.
3. En el repositorio abre Settings > Pages.
4. En Source elige Deploy from a branch.
5. Selecciona main y /(root), y pulsa Save.
6. Cuando termine la publicación, GitHub mostrará la dirección del sitio en esa misma sección.

No subas el ZIP como archivo: sube los archivos descomprimidos. Conserva .nojekyll, que desactiva el procesamiento de Jekyll.

Puedes usar un repositorio llamado AlbertoEGonM.github.io para publicar en https://AlbertoEGonM.github.io/, o un repositorio de proyecto con otro nombre. Las rutas de los recursos son relativas y funcionan en ambos casos.

## Editar
- index.html: presentación, proyectos y tecnologías.
- styles.css: diseño y estilos para celular.
- app.js: idioma y presentación de certificados.
- certificates.js: datos de los certificados.
- assets/: certificado PDF y vista previa.

No requiere instalación de dependencias ni un backend. Las fuentes de Google Fonts requieren internet; hay fuentes alternativas del sistema.

Guía oficial: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
